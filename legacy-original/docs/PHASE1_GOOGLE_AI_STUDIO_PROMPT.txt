DEFENDER/SMARTSCREEN REQUIREMENT
The goal is NOT to bypass Defender or SmartScreen.
Identify implementation patterns that may legitimately trigger security products and propose safer implementations.
Review specifically for:
- ExecutionPolicy Bypass
- encoded PowerShell
- Base64 command execution
- Invoke-Expression
- hidden shell execution
- download-and-execute flows
- temporary executable execution
- Defender exclusion creation
- Defender disabling
- SmartScreen disabling
- firewall disabling
- UAC bypass behavior
- unvalidated arbitrary command execution
- broad localhost listeners
- wildcard CORS
- hard-coded credentials/API keys
- self-extracting/embedded executable chains
- unnecessary permanent administrator execution

Preserve the business function where possible, but refactor unsafe implementation patterns.
